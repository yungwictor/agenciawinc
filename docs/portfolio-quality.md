# Portfolio quality notes

## Business problem

The agency site introduces service offers and routes prospective clients to the correct briefing, reducing vague enquiries and helping the team qualify scope earlier.

## Demonstrative targets

These are delivery targets, not client analytics:

| Signal | Target |
| --- | --- |
| Service-to-briefing completion | 5–10% |
| Mobile performance | Lighthouse Performance 90+ |
| Accessibility | Lighthouse Accessibility 95+ |
| Briefing completeness | At least service, goal and contact supplied |

## Accessibility checklist

- [x] Dedicated briefing paths by service
- [x] Static SEO metadata, sitemap and robots support
- [ ] Test all briefing forms with keyboard and screen reader
- [ ] Re-audit contrast after asset updates
- [ ] Run Lighthouse on the Netlify production URL

The repository does not include submitted client briefings or personal lead data.
